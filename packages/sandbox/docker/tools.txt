CTF SOLVER TOOL REFERENCE
=========================

Prefer deterministic, non-interactive commands. Request JSON or machine-readable output
when available, add explicit timeouts in the calling Agent, and write generated files under
/workspace.

LANGUAGE RUNTIMES
  /usr/local/go/bin/go version
  /usr/local/go/bin/gofmt -w ./source.go
  /opt/jdks/8/bin/java -version
  /opt/jdks/17/bin/java -version
  /opt/jdks/21/bin/java -version
  vineflower ./input.jar /workspace/decompiled
  cfr ./input.class --outputdir /workspace/decompiled

  Go 1.26.5 is installed under /usr/local/go; add /usr/local/go/bin to PATH when needed.
  Java is intentionally absent from the default PATH. Select /opt/jdks/8, /opt/jdks/17,
  or /opt/jdks/21 explicitly through an absolute path or JAVA_HOME. Vineflower uses JDK 21;
  CFR uses JDK 8 for older bytecode.

  stegolsb provides deterministic PNG/BMP and WAV LSB recovery; specify the bit count
  and, for WAV, an explicit byte count. stegseek targets steghide carriers and needs an
  explicit wordlist for cracking. Keep extraction output under /workspace; foremost
  requires a new, non-existing output directory for each run.
